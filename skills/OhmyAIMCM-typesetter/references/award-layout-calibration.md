# 国赛优先的阅读关系与离线布局校准

仅在组织完整中文国赛稿的图文布局、或明确研究新样式时读取。默认样式与正式
合规门禁仍由 [aesthetic-policy.md](aesthetic-policy.md) 管理；本文件不是第二个
样式选择器，不在渲染时读取语料或训练模型。

## 借鉴的是阅读关系

获奖论文的可用经验首先来自一个局部单元如何帮助推理，而不是整篇像素模仿：

| 当前阅读困难 | 可采用的局部安排 | 不继承的历史缺点 |
|---|---|---|
| 口头条件到约束式跳跃 | 条件段→局部构型→不等式；图中标同名对象 | 缩小长公式塞满一页 |
| 单视图藏住自由度 | 侧视与截面相邻、共用符号；明确是同一对象 | 用三维装饰替代真实投影关系 |
| 结果很多但不知道看哪里 | 总览→选取局部的理由→局部证据 | 只展示有利样本、把全量柱图压成色块 |
| 方案编号不能执行 | 比较表→选定动作解码，精确数值保留表格 | 二进制长串塞进摘要，色底作为唯一编码 |
| 过程可行性难以复核 | 同一布局的关键状态、动作与后状态表 | 没有方向和载荷的彩色连接线 |
| 多面板缺比较关系 | 按同一对象/条件对齐面板，正文连接关键差异 | 子图标签和图体跨页分离、默认跨色尺比较 |

这些是选择项而非固定网格或图种配额。图不一定需要彩色；需要颜色时给它清楚的
对象、区域、方向或状态语义。圆角本身不是错误，但空洞节点、阴影与大面积彩底
不能代替科学关系。不能画出有依据的机理时，清楚的统计图或短表就是合适的选择。

让定义、必要图式与承担解释的文字就近出现，但不强制所有内容同页、不滥用浮动
锁定。保留可读字号、段落节奏和合理断页。长表需要重复表头和续表标识，公式
需要逻辑分行；不要因样本页更密就压缩至不可读。摘要提炼结果及条件，不复制
获奖稿的大量方法加粗、软件名和九位小数。

## 加权口径：先分语料，再在语料内按篇等权

本轮离线共同几何重测覆盖64篇国赛稿及既有752个期刊语料身份。国赛总质量设为
0.60，期刊为0.40；分别按64和752篇分配，不能直接把816篇混在一起一篇一票，
否则数量更多的期刊会淹没国赛特征。0.60是针对国赛任务的设计偏好，不是实验
发现的最佳比例，也不表示任一获奖稿有60%的可信度。

仅对两组原始布局块使用同一归一化坐标和文字筛选规则，测量文本外包络面积、
左右文本边界。期刊保留原生文本/OCR来源，不能把全部期刊称为OCR；语言、分栏、
块分割和正文边界识别仍不相同。没有利用像素高度反推pt字号，没有把缺失量填零。
正文候选特征覆盖国赛64/64、期刊750/752；两篇缺失保留其身份和缺失质量。

0.60下，文本外包络面积的加权中位数为0.5108075；左/右文本边界比例为
0.112/0.115。外包络不是实际墨迹面积，也不是所有文字框面积并集，更不是正文
应达到的密度目标。这里的边界不是直接可替换的LaTeX页边距。

比例敏感性：国赛质量0.50/0.60/0.70/0.80时，面积中位数约为
0.5357/0.5108/0.5027/0.4876。逐年留出时，0.60下该中位数在0.5053–0.5237
之间，左右边界中位数保持0.112/0.115；真实medoid随留出变化，不能据此称模板
身份稳定。字母组留出是元数据分层检查，不是按题型规定模型或版式。

聚类代表采用观测到的整篇三特征medoid，而非拼接若干边际均值。medoid只是几何
代表，不是整篇科学与美学合格证。错误公式、未验证的最优性、装饰图和难读截图
不能因为所属论文的源权重增加而获得推荐资格。

## 进入正式样式前还有什么边界

这次校准实际改变的是离线混合权重和条件性布局引导，`runtime_transfer_eligible`
仍为false。既有752个身份是发现语料，只有21个publisher-final锚点，不改写其
来源可信度。原页选样视觉审读与全语料几何测量不是每页视觉验收。

若需要新运行样式，应按既有证据门禁完成来源、可读性、断页、图式衔接与整篇对照
验证后再明确选择。此前对旧样式的偏好记录不能替新模型签收；不能因本轮国赛
加权就覆盖用户选择的 `journal-dense-cn-v1`。
