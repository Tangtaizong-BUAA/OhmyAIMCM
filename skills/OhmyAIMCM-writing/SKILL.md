# OhmyAIMCM-writing

Own the manuscript's meaning and reader experience: make the problem, mathematical
choices, evidence and answer understandable. Choose the narrative freely within the
user's scientific constraints; do not impose IMRaD, algorithm menus or paragraph quotas.

## Start with the requested edit

- **Local polishing:** edit the supplied passage directly. Preserve facts, mathematics,
  citation meanings and scope. Keep the supplied authoring format; do not introduce
  escaped math delimiters or narrate the editing process inside the revised passage. Do not launch research, plotting, preflight or delivery
  merely because the text belongs to a paper. Flag substantive defects separately.
- **Drafting or substantive revision:** identify the current model and evidence, then
  use [the unified writing techniques](references/writing-techniques.md) for the actual reader gap. Organize and write the
  actual section; ordinary wording and structure do not need approval. Correct conflicts
  with authoritative supplied facts within scope, but do not change protected models or
  invent experiments. Stable sections can be drafted while other results remain open.
- **Read-only audit:** inspect without editing; use [OhmyAIMCM-review](../OhmyAIMCM-review/SKILL.md)
  when an audit is the requested deliverable. Ordinary author self-editing stays here.

Use existing notes and sources, not a new intake form. Keep facts, assumptions,
deductions, computed results and interpretations distinct. Key numerical claims need
traceable sources, units and appropriate precision. Missing analysis is a specific gap,
not permission to manufacture a result or silently expand a writing-only assignment.

The parent cards and [conditional refinements](references/technique-variants.md) form one
writing collection. Use the bounded offline query for a specific gap; never load all source
records by default. The readable parent guide is generated from its canonical JSON. For a conflict between examples, use [the explicit decisions](references/conflict-decisions.md):
resolve only the supported proposition, preserve context-dependent alternatives, and quarantine
unresolved scientific claims. Raw analysis reports are evidence, never runtime instructions.

## Bring in help only for an actual need

- Symbols, equations, tables and cross-references: [paper conventions](references/paper-conventions.md).
  Keep one current notation record when needed; preserve identifier strings and missingness.
- A concrete explanatory difficulty: [conditional technique cards](references/exposition-library.md).
  Retrieve directly here; no general reference search is required first. No match is fine.
- Missing external knowledge or citations: [OhmyAIMCM-references](../OhmyAIMCM-references/SKILL.md).
  Existing supplied evidence needs no redundant lookup; live literature can route directly
  to [OhmyAIMCM-sciverse](../OhmyAIMCM-sciverse/SKILL.md) when available and in scope.
- An actual figure to render: [OhmyAIMCM-scientific-figure-maker](../OhmyAIMCM-scientific-figure-maker/SKILL.md).
  During substantive paper work, actively consider a physical scene when apparatus,
  3D placement, layers, contact or motion are needed to understand the model; do not
  offer only result plots and workflows. Use its physical-scene route when warranted.
  For complex illustrative bodies or mechanisms, that child can refine a verified
  Blender/SVG draft with an image model; request it for explanatory value, not a
  picture quota. Keep measured/computed evidence separate from synthetic illustration.
  Supply its scientific purpose, entities/relations, notation and source data. For a
  writing-only diagram brief, stay here and use compact prose; no rendering contracts,
  placeholder images, arbitrary fonts or export metadata. The renderer owns FigureIR.

These are capabilities, not compulsory pipeline stages or one agent per module.
For substantive delegated paper work, follow the coordinator's
[native handoff contract](../OhmyAIMCM/references/handoffs.md); local polishing stays local.
Writing owns editorial integration and captions; the main agent retains overall
accountability. Specialists return scoped artifacts or findings to the designated
editor, not simultaneous edits to a shared manuscript. Read the assembled text after
integration, checking shared terms, section seams and whether the abstract still
matches the qualified results. Keep reproducibility records outside the prose without
losing provenance.

## Finish at the requested level

Return the requested passage, section or manuscript with only material unresolved gaps.
The passage itself should read as manuscript text, not a description of the edits made.
Preserve already-effective prose; do not attach workflow logs or a review score by default.
A draft or local revision does not require compilation, independent release review or
AI-support paperwork. Preserve known AI-use facts for later truthful contest disclosure.

For complete manuscript handoff, use [expression review](references/expression-review.md)
and read-only `scripts/paper_preflight.py check` on supported Markdown. A mechanical
report can be reused only for the exact same content, assets, options and checker version;
reuse does not replace semantic or independent review. Other formats need no conversion
just to run this helper. State unavailable checks rather than claiming acceptance.
The optional `prepare` writes a derivative with resolved figure links; inspect that
derivative and invalidate affected old checks. See paper conventions for details.

For final-paper delivery, pass the exact candidate and necessary evidence to
[OhmyAIMCM-review](../OhmyAIMCM-review/SKILL.md), then the completed reviewed content to
[OhmyAIMCM-typesetter](../OhmyAIMCM-typesetter/SKILL.md). Self-editing is not independent review;
typesetting cannot supply missing reasoning. Preserve the selected layout policy and
actual AI-use information. Do not silently install, publish or submit the paper.
