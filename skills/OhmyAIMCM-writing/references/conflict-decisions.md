# 冲突裁决与条件分支

统一不是让相反的句子都进入提示词，也不是把事实疑点修饰成无争议结论。
当前任务事实和用户约束决定正在写什么；旧资料只提供有定位的表达经验。
具体来源有后续原件回查时，采用其已核实的命题，不能按文件新旧、作者声望或出现次数替代证据。
本表规定技巧如何使用；它不重新裁定所有原论文的数学问题。

## 可以并存的选择

| 表面冲突 | 统一选择条件 |
| --- | --- |
| 先给结论 / 先铺垫 | 对象和尺度已清楚时先给判断；结果需要陌生定义才能理解时先提供必要定义。不要求每段同时遵守两种顺序。 |
| 简洁 / 展开推导 | 展开会改变结论或需读者自行补推的一跳；常规代数与运行日志可入附录。不能删除关键假设，也不为篇幅填充教材。 |
| 跨问复用 / 各问独立 | 只传递真正共享的对象、关系或输出；条件变化就地解释。问题没有依赖时保留并列，不编造递进故事。 |
| 正文解释 / 图注自足 | 图注给出读图所需对象、编码、条件与单位；正文说明哪条关系支持判断。重复事实可压缩，证据含义不能丢失。 |
| 机制示意 / 统计图 | 根据实际理解困难选择。示意解释关系，统计图呈现数据；有三维空间困难才采用相关视图，无图也可完成简单解释。 |
| 归一化比较 / 保留原始量 | 比较对象规模或量纲不同才说明相应变换；同时保留必要的总量和分母。不是所有目标都要无量纲化。 |
| 保真润色 / 修正错误 | 局部保真任务不暗改科学承诺；实质修订可依已确认事实修正。定义或原件本身冲突时报告具体缺口，不能猜一个顺畅答案。 |
| 修订建议 / 已执行结果 | 实际做过的检查才报结果；未做的建议保持建议。写作可以说明如何检查，无须擅自新增实验。 |
| 来源有缺陷 / 表达可借鉴 | 有缺陷的论文仍可能提供有用组织动作；只迁移经过回查的动作，不继承其数字、模型或正确性保证。 |

## 已排除的错误推断

| 冲突或误读 | 采用决定与关联技巧 |
| --- | --- |
| 拟合收敛、模型内回代、扰动方向一致被写成外部预测正确或物理参数唯一 | 按实际检查分别写内部一致性、敏感性、外部比较和可辨识性；不能互换。`physical-07`、`physical-09`、`statistical-07`。 |
| 局部贪婪、网格最优、必要条件或若干一致算例被写成全域证明 | 明确可行域、候选集与边界；界和达到界的构造分别说明。`argument-31`、`argument-32`。 |
| 光线点数、轨迹外观或立体高程图被写成照度、防眩或安全证明 | 只保留图实际表示的量；物理量还需要相应权重、面积、标定和依据。`argument-33`、`physical-04`。 |
| 精细理论与简化实现并排，默认计算保持理论精度 | 写明实际替换及代价；共同改变的采样与归属规则不归因于单一参数。`argument-34`。 |
| 96%、100%、95%等不同分母统一叫准确率，243.5%出游率被改成去重人口比例 | 回到对象、单位、真实标签和分母。百分数保留原指标身份。`statistical-04`、`statistical-07`。 |
| 英文摘要、正文和表格排名矛盾，选择最好看的版本 | 对同一命题逐项回查；有确定依据才更正，否则保持未决或移除未支持的结论。`statistical-06`、`notation-01`。 |
| 灰度α/β被解释为几何校正，“长比划”误作“长比例” | 后续原页确认参数是灰度比例/偏离；仅保留实际参数解释与两侧阈值损失。`decision-01`。 |
| 多候选分支有人工介入，所以其余流程全自动 | 实际分支之后仍有人工作业；按完整接口描述自动化范围。`interface-01`。 |
| 两张worksheet等于两份统计表，或同篇附件、异版OCR等于独立证据 | 该批第二sheet为隐藏CNKI单元格；50文件仍是同一年鉴集合的50表。异版和附件不增加独立支持。`source-01`。 |
| 表头单位字段的自动抽取就是完整口径，或引文坐标命中就支持全部观点 | 主题组标签与自动抽取可能漏项或套用。实际采用回到具体表头、上下文和主审取舍；原候选不自动加入技巧。`source-01`、`notation-01`。 |
| 旧稿被纠正后仍与新稿并列投票 | 有明确替代关系的旧判断退出当前采用；留作历史证据，不能用旧稿数量压过定位纠正。 |
| 历史制度、软件名、作者自评、教材示例或“获奖目录”证明当前建议有效 | 只保留历史或示例身份，不迁移为现行规则、工具权威或通用性能承诺。 |

## 来源与维护边界

原有34项技巧保存原页定位和已知缺陷；新增与补充条目链接到有SHA及定位的分析回查，详见[结构化技巧库](exposition-cards.json)。
仓库维护记录位于`experiments/writing-corpus-20260909/skill-unification-001/`，包含全部分析文件处置、旧版备份、历史与近期裁决以及前向试用结果。
卡片中的报告路径用于回溯；普通写作无需加载语料或历史日志。

未解决的原公式、缺失页或数据问题保留在资料盘点中。统一Skill表示本次采用的写作指令已归并和校核，不表示全库科学结论已消除矛盾，也不表示42项技巧已经证明优于其他写法。


## 全部候选的条件收敛（skill-unification-002）

6,230 条原候选及补充分析已逐项建立去向。跨源同义动作归并，适用条件不同的保留为细分；临时分类不合不能成为排除理由。题面要求、行政通知、纯算法实现建议与缺乏可迁移表达动作的记录，保留具体排除理由，不伪装成写作技巧。

- 先给直觉与先给定义分别适用于不同知识缺口；类比标明对应与失配，不提升为证明。
- 方法、指标或参数选择建议只迁移为解释本研究已经采用的选择及其依据，不强迫新增建模操作。
- 理论界、已构造方案、搜索覆盖、停止条件分别呈现；停止不等于最优证明。
- 输入、重建、展示与实际检验范围分别交代；初试、未完成步骤、后续建议不得混称完成。
- 矛盾先对齐条件、时间、分母、证据层级与来源；可兼容的条件分支均保留，无法核实的命题维持未决。
- 来源角色、程序接口、变量定义等常规表达在存在实际误读风险时有用，不因常见而排除，也不要求每篇论文机械重复。

细分的原候选成员、定位和排除记录在 technique-variants.json；本轮追溯表位于 experiments/writing-corpus-20260909/skill-unification-002/candidate-dispositions.csv。原科学结论仍受材料自身证据限制。此前第一轮 42 卡审计作为历史记录保留。
