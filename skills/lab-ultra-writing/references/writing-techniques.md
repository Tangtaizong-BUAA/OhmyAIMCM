# 统一写作技巧

从当前读者的理解困难选用，直接写成所需段落。已经清楚的内容保留；没有适合的卡可以自行组织。
这些技巧说明如何表达，不选择算法，不规定章节、图表或句子数量，也不补造研究结果。

## 先处理真正影响表达的分歧

局部保真润色保留科学承诺，遇到实质矛盾单独指出；实质修订可按确定的任务事实修正受影响表达。
不同结论先核对对象、分母、条件、信息时点和来源角色。条件不同则分别保留；同一命题确有矛盾且无法裁决时，保持未决，不以多数票、最新日期或流畅程度决定真伪。
直观解释不能取代证明，内部一致性不能改称外部验证；验证活动可以描述，但要说清检查对象、参照和实际范围。
何时先给结论、推导写多长、是否加图，按读者是否已具备必要定义和证据选择。详细裁决见[冲突与采用边界](conflict-decisions.md)。

具体条件与来源归并见[条件细分检索](technique-variants.md)，按需检索，不全量加载。

## 任务与组织

<a id="statistical-06"></a>
### statistical-06

**读者困难：**摘要堆满模型名和数字，读者仍不清楚每问解决什么、能据此采取什么行动。

**写作动作：**每个子问题只保留困难或目标、关键建模动作、带单位和口径的主要结果、适用范围；将完整参数表留给正文。压缩后反查区间是否互斥、数值与比例是否相容、方向是否与正文一致。

**适用条件：**正文已有可追溯的主要结果，摘要需要在有限篇幅内独立回答任务。

**先有这些依据：**每问对应的最终结果表；指标时间窗、单位与分母；结果适用条件；摘要与正文的数值及方向核对。

**不要据此推出：**用密集算法名替代推理；为显得成果丰富抄入全部区间；把模型输出数量当准确率；静默修补来源中的明显矛盾。

<a id="reader-01-answer-and-audience"></a>
### 答案与受众

**读者困难：**同一题目背景下，正文回答的量或受众与实际交付要求错位。

**写作动作：**先确定本段交付给谁、需要回答哪个量或选择。公众说明将技术编码转成可理解的行动和随机性解释；技术正文保留使判断可复核的定义。不同子问只复用真正共同的内容。

**适用条件：**题目或用户已指定交付对象和用途；无需重写已清楚的题目背景。

**先有这些依据：**实际任务及受众；待交付的量、单位和适用条件。

**不要据此推出：**把论文结论直接当公众说明；复用历史购买建议或规则；强制所有论文写报纸短文。

<a id="writing-unified-23"></a>
### 跨问题依赖衔接

**读者困难：**跨问复用抹平条件变化。

**写作动作：**只传递真实共享对象和关系，并说明新增条件。

**适用条件：**多个问题存在实际依赖。

**先有这些依据：**共享对象；新增条件。

**不要据此推出：**同名变量不证明结论可复用。

<a id="writing-unified-25"></a>
### 问题拆解与任务组织

**读者困难：**多个实际子问题的交付量和依赖关系容易被固定模板掩盖。

**写作动作：**呈现已采用的拆解，标出各子问题的回答量、输入输出和真实依赖。

**适用条件：**确有多个相互依赖的研究问题或交付量。

**先有这些依据：**子问题、输入输出和依赖。

**不要据此推出：**不为结构新增问题或用顺序替代结果。

<a id="writing-unified-26"></a>
### 题意与交付保真

**读者困难：**重参数化或改目标后，原题对象和交付物容易被新表示遮住，读者需要知道哪些要求尚未交付。

**写作动作：**先列出题目要求的对象、量、单位、条件和交付物，再标注模型变换保留、改变和未交付的部分。

**适用条件：**重参数化、改目标或改表示可能改变题意交付。

**先有这些依据：**题目要求、映射表、未交付项。

**不要据此推出：**不能用新变量或新目标掩盖原任务未回答的部分。

## 对象与推导

<a id="physical-09-shared-and-condition-specific"></a>
### physical-09-shared-and-condition-specific

**读者困难：**多组观测一起拟合，读者却不知道哪些参数描述同一对象，哪些差异只是测量条件改变。

**写作动作：**先辨明实验中保持不变的对象及改变的条件，再把共同物理量与条件特定的校准量分别命名。沿这一分工解释每组观测怎样进入同一目标；将共享假设、数值估计和可辨识性论证分开，不让一个求和号代替理由。

**适用条件：**同一研究对象在多种测量条件下被观测，且确有理由共享部分量；若对象、状态或机制已改变，应允许分别建模或重新说明共享范围。

**先有这些依据：**哪些观测来自同一对象、哪些条件改变的记录；各参数的物理含义与依赖条件；用于支持精度、可辨识性或稳健性主张的实际检查，如有。

**不要据此推出：**强制所有多组数据联合拟合；把共享一个参数写成证明其唯一可辨识；把校准项吸收差异解释为物理模型必然正确。

<a id="geometry-01-definition-discriminator"></a>
### geometry-01-definition-discriminator

**读者困难：**同一个指标有两种看似合理的定义，读者无法知道选择依据，而结果表只是并排报数字。

**写作动作：**先把两种定义的分子、分母及参考对象画到同一个具体构型上，再挑选能让两定义产生不同判断的边界情形；用实际几何交叠或其他可独立核算的关系说明选择依据。图中点、线段必须直接对应公式对象，正文说清哪一判断被排除。

**适用条件：**定义存在真实歧义且可找到具有判别力的构型；先确认任务本身未给定唯一口径。

**先有这些依据：**每个定义的对象和参考分母；独立几何计算或实验参照；边界、单位和负值的解释。

**不要据此推出：**只凭示意图看起来重叠就宣布一个公式普遍正确；用漂亮图替代数值几何核验；把选择定义写成验证模型。

<a id="geometry-02-geometric-lemma-before-application"></a>
### geometry-02-geometric-lemma-before-application

**读者困难：**空间图太复杂，多个投影角同时出现，读者无法知道公式中的角度由哪里来。

**写作动作：**把复杂场景中反复使用的几何关系抽离成一幅仅含必要垂线、投影和角度的小构型，先解释该关系；再回到实际场景图，逐项说明哪条线对应抽象构型中的哪个对象，最后代入前面已经建立的模型。

**适用条件：**实际场景可复用一个低维或局部几何关系，抽象没有删除影响结论的自由度。

**先有这些依据：**投影与正交条件；图文同一套有向角约定；特殊方向或退化情形检查。

**不要据此推出：**图上写一个角，公式却使用另一个角；把无向角几何照搬到需要方向符号的计算；为简单二元关系硬拆两幅图。

<a id="physical-01-data-to-motion-assumption"></a>
### physical-01-data-to-motion-assumption

**读者困难：**读者知道装置有多个空间坐标，却不知道为什么节点只剩一个径向自由度。

**写作动作：**在写运动简化前，先说明附件编号怎样把部件对应起来，再给出可计算的几何偏离量及其量级，最后说明该观察支持哪一种运动方向近似，并就地定义正负方向。这样把数据处理变成假设的理由。

**适用条件：**运动方向简化能够由已有几何数据检查，且偏离量对后续预测的影响可以评估。

**先有这些依据：**配对规则与未匹配记录；偏离量分布及异常点；量级阈值如何关联输出误差。

**不要据此推出：**用绝大多数接近某条件直接断言所有对象满足；只报一个微小量级但不处理反向共线或异常点。

<a id="physical-02-proxy-handoff"></a>
### physical-02-proxy-handoff

**读者困难：**一个简化指标给出了方案排序，但读者不清楚它与实际总成本是否一致，也不清楚下一问为什么还要计算同一对象。

**写作动作：**在比较曲线后解释误差发生在哪里，以及该位置聚集多少实际对象；明确当前量只是代理指标，并把下一问的具体数据计算指定为核验该排序的任务。跨问衔接传递的是待检验命题及数据需求。

**适用条件：**早期模型用连续密度、抽样或几何代理近似离散执行成本，后续拥有更细的对象数据。

**先有这些依据：**代理量的权重来源；实际逐对象成本的定义；两方案采用同一实际口径的比较。

**不要据此推出：**把下一问将验证写成已经证明；仅凭图形面积或局部峰值宣布总成本最优。

<a id="physical-03-frame-force-equation"></a>
### physical-03-frame-force-equation

**读者困难：**读者看见耦合微分方程，却不知道位移相对谁测量、内力为何以相反符号出现，以及重力为何没有单列。

**写作动作：**先定义固定参考系和随体参考系，给出相对量与绝对量的换算；再按受力对象拆图，并把每类力写成相应状态量的函数；最后合成成对运动方程，说明静平衡项如何被吸收入恢复力。

**适用条件：**存在耦合物体、参考系切换或静平衡附近线性化，读者容易混淆内外力。

**先有这些依据：**坐标原点与正向；各物体自由体图和力定义；平衡消项及作用反作用核对。

**不要据此推出：**装置图直接代替自由体图；省略静平衡解释后删除重力；随体坐标有转动却照搬平动关系。

<a id="physical-04-geometric-event-predicate"></a>
### physical-04-geometric-event-predicate

**读者困难：**阴影或遮挡这样的现实事件，怎样从图中的光路变成可编程判断，而不把延长线交点误算为实际拦截？

**写作动作：**先固定向量朝向，再把事件拆为交点存在、交点落在有限面域、交点位于传播有效方向等可检查条件；随后定义事件指示量，用同一批对象的成功计数构造比例。图负责解释方向和区域，方程负责给出判断规则。

**适用条件：**需要把可视空间事件转成仿真条件，且有限对象边界、方向与采样总体均已定义。

**先有这些依据：**直线或射线参数及有效区间；有限面域与边界点规则；计数分母对应的总体及时间聚合方式。

**不要据此推出：**仅求无限直线与平面交点就宣布遮挡；把条件比例和无条件比例相乘而重复扣损失。

<a id="physical-05-local-geometry-to-recursion"></a>
### physical-05-local-geometry-to-recursion

**读者困难：**整体队列有大量节点，读者不知道为什么只求一个局部几何关系就能确定全体位置。

**写作动作：**先交代首节点如何由行进长度定位，再固定一对相邻节点，把路径约束和两节点距离约束分别写出；配图标明这两个约束共享的角度与长度。最后说明局部求解的输入、输出以及如何把输出作为下一次输入。

**适用条件：**相邻关系可以封闭局部未知量，初始节点已知，分支规则可保证物理连接次序。

**先有这些依据：**首节点定位；局部约束独立性；多根时的物理分支与求根区间；递推后的全局约束检查。

**不要据此推出：**把两节点之间的直线距离替换为路径弧长；只说二分求根却没有确定括区与根的物理含义。

<a id="physical-06-constraint-to-velocity"></a>
### physical-06-constraint-to-velocity

**读者困难：**两个连接点沿不同切线运动，为什么可以从一端速度推出另一端速度，又为何不能说两端速率相同？

**写作动作：**把刚性约束翻译成沿连接方向的速度投影相等，再从位置模型获得切线与连线方向，最后组成速度传递关系。跨路径推广时，明确保持不变的是投影约束，需要替换的是各段切向方向。

**适用条件：**连接件不可伸长，轨迹可微；跨分段路径时已定义连接处切向和状态所属段。

**先有这些依据：**定长约束的时间导数或同等理由；切向量的有向定义；投影分母接近零时的处理；分段连接处的一致性。

**不要据此推出：**把投影相等写成速率相等；用无向锐角抹去运动方向；未经检验把某时刻某节点的最大速度推广为全局最大。

<a id="physical-07-forward-before-inverse"></a>
### physical-07-forward-before-inverse

**读者困难：**待测厚度没有直接观测，读者不知道它怎样影响谱线，也不知道最小二乘到底比较了什么。

**写作动作：**先沿物理传播链说明未知量如何进入光程、相位与可观测信号；把材料参数和目标参数一并标成待定量；再在下一段把前向输出与实测同类量配对，形成带明确参数的残差目标。

**适用条件：**测量的是目标参数经物理机制产生的间接响应，且有可审计的前向映射。

**先有这些依据：**前向模型的近似与适用波段；观测与预测单位一致；目标参数与干扰参数的区分；参数可辨识性及残差诊断。

**不要据此推出：**把拟合收敛当成参数唯一；省略干扰参数；未说明极化或透射项就复制源论文的反射公式。

<a id="physical-08-initialization-and-validity-domain"></a>
### physical-08-initialization-and-validity-domain

**读者困难：**为什么先做频域初估又做非线性拟合，以及为什么允许剔除一段观测数据？

**写作动作：**给每一步独立的证据角色：近似周期关系只提供初值，完整前向模型负责精化，多条件数据用于一致性检查；预处理则先说明哪一物理机制使某波段不再符合当前模型，再说这种失配如何影响后续计算。

**适用条件：**存在可靠的低成本近似可初始化精细模型；某些观测区间有明确的模型失配机制。

**先有这些依据：**近似关系的成立范围；多初值或参数范围检查；剔除区间的机制证据和阈值敏感性；独立条件的检验结果。

**不要据此推出：**把初估值当最终答案；看到难拟合区间就事后裁掉；在声明联合拟合后仅报告两个独立拟合数值。

<a id="argument-33-local-unit-and-aggregation"></a>
### 从局部解释整体

**读者困难：**从几何落点直接跳到能量、总量或全体结论，读者看不见汇总依据。

**写作动作：**挑一个保留关键关系的单元，说明输入、输出、权重或面积，再解释怎样合成整体。若采用极简对照例，明确保持哪些量、改变哪些量，用它解释运算的作用。

**适用条件：**单元规则确能组成整体，且例子未删掉影响推理的边界与依赖。

**先有这些依据：**单元到整体的聚合关系；面积、权重、守恒或分母；例子的构造范围。

**不要据此推出：**将点数当作照度；将直观例子当总体正确性证明；强制每个公式都配算例。

<a id="writing-unified-01"></a>
### 假设与符号解释

**读者困难：**公式掩盖现实约束和参数理由。

**写作动作：**先解释假设和参数含义，再给符号表达。

**适用条件：**公式需要现实语义支撑。

**先有这些依据：**采用的假设；参数定义。

**不要据此推出：**符号堆叠不能替代依据。

<a id="writing-unified-10"></a>
### 方法比较与权衡

**读者困难：**方法排序容易隐藏共同任务、信息权限、代价和评价条件，使一次比较被误写成跨场景推荐。

**写作动作：**比较方法或方案时，先固定共同任务和评价条件，再按少数会改变选择的维度说明差异、代价和适用边界；不把排序写成普遍推荐。

**适用条件：**存在真实候选差异且比较条件、信息权限和评价指标可对齐。

**先有这些依据：**共同任务、比较维度、同口径结果、未覆盖情形。

**不要据此推出：**不以单次结果、权威案例、工具偏好或未核实性能承诺给出跨场景排序。

<a id="writing-unified-11"></a>
### 机理定律到方程

**读者困难：**方程来源不透明。

**写作动作：**从定性关系、守恒或定律逐步说明方程。

**适用条件：**方程由机理或极限推导。

**先有这些依据：**定律依据；变量关系。

**不要据此推出：**公式不能替代依据。

<a id="writing-unified-14"></a>
### 模型变换与适用边界

**读者困难：**代理、离散化和模型转换会悄悄改变对象或约束，读者需要看到保留项、丢弃项和适用边界。

**写作动作：**说明从原问题到新域、代理量、离散化、隐函数或经典模型的映射，交代保留、改变和丢弃的约束，并把近似误差与适用范围放在同一处。

**适用条件：**实际采用了变换、代理或近似，且其输入输出和边界可追溯。

**先有这些依据：**原始对象、变换规则、保留/丢弃关系、误差或验证。

**不要据此推出：**不要把转化步骤当作算法处方或等价性证明；没有双向映射和证据时保留为假设。

<a id="writing-unified-15"></a>
### 特例一般与结构化推导

**读者困难：**局部算例或教学顺序容易被读成全域结论，缺少特例覆盖范围与一般化条件的标记。

**写作动作：**使用特例、局部单元或分阶段推导时，标出保留的关系、放宽的条件及一般情形新增的证明或数据；每一步说明它对结果或解释范围的贡献。

**适用条件：**特例确实保留了会影响结论的关键关系，且一般化所需条件可列出。

**先有这些依据：**特例覆盖/未覆盖对象、一般化条件、对照或验证范围。

**不要据此推出：**不把教学顺序、局部算例、解析猜想或某个算法步骤写成全域结论。

<a id="writing-unified-19"></a>
### 结构性假设与参数角色

**读者困难：**增加参数或随机项可能只是表示自由度变化，若不交代可辨识性和约束，读者会把拟合项当成机制。

**写作动作：**介绍模型结构时，先说明对象、自由度、参数依赖和假设，再解释新增项或参数怎样改变输出；将表示冗余、代理项和未观测因素分别标注。

**适用条件：**复杂模型中参数角色、自由度或未观测因素容易被混为一谈。

**先有这些依据：**参数角色、约束/自由度、可辨识性及实证范围。

**不要据此推出：**不能用增加常数、随机项或参数拟合把未知机制伪装成解释，也不能把表示唯一写成对象唯一。

<a id="writing-unified-24"></a>
### 逻辑约束与数值编码

**读者困难：**业务规则的形式编码容易被误读为现实机制。

**写作动作：**呈现已采用的逻辑依赖、分段或线性化编码及其实际界限和数值风险。

**适用条件：**模型确含相应编码。

**先有这些依据：**业务规则、编码、界限和风险。

**不要据此推出：**不要求新增编码或使用无界参数。

## 定义与口径

<a id="notation-01-text-equation-direction"></a>
### 文字和数学说同一条件

**读者困难：**文字、符号、图和表都在，但不等号方向、指标方向或对象不同。

**写作动作：**在关键式旁把比较对象、约束方向与可行含义译回文字；结果解释核对同一对象、指标、分母和排序。度量越小越好或越大越好来自其定义，不来自分数的常见习惯。

**适用条件：**约束或评价指标会影响选择；已有明确的定义可供对照。

**先有这些依据：**原定义与不等式；结果表和排序对象；单位及指标方向。

**不要据此推出：**凭图形或惯例猜作者本意；在保真润色中静默改公式；保留错误排名只因为正文已经这样写。

<a id="writing-unified-09"></a>
### 数据变量与指标语义

**读者困难：**下标、单位、分母、权重和代理量若只给符号，读者会把计算方便误当成业务含义。

**写作动作：**给出变量、索引、分子、分母、单位和中间量在当前业务中的角色，说明它们真正改变哪个目标或状态；变换后丢失的原意要明写。

**适用条件：**下标、聚合、标准化或代理指标可能造成对象和口径误读。

**先有这些依据：**字段/变量定义、单位分母、一个最小代回或对照。

**不要据此推出：**不能把任意权重、归一化或复合指标当作真实含义，也不能用分数习惯猜指标方向。

<a id="writing-unified-13"></a>
### 概念边界与命名

**读者困难：**读者容易把同名术语、相似指标或新变量当作同一对象，因而看不出定义差异怎样改变判断。

**写作动作：**相似术语、模型或指标出现时，先给出会改变判断的定义差异，再说明本文采用的含义；命名或类比只保留能被当前对象和条件支撑的部分。

**适用条件：**术语确有重叠且差异会改变模型、指标或读者操作；单纯背景介绍不适用。

**先有这些依据：**定义、对象、输入/输出边界及至少一个会改变判断的例子。

**不要据此推出：**不要靠名词堆叠、权威名言或漂亮类比制造差异，也不要把一个领域的名称直接当作另一个领域的等价物。

<a id="writing-unified-18"></a>
### 类比映射与失配声明

**读者困难：**抽象对象需要直觉映射，但类比可能被误读为机制。

**写作动作：**逐项写出源域与目标域的对应和失配；类比只作直觉辅助，正式定义、公式和证据另列。

**适用条件：**确有抽象映射困难且类比保留关键结构。

**先有这些依据：**对应关系、失配项和适用边界。

**不要据此推出：**不能把隐喻写成机制证明、性能保证或选型依据。

## 选择与取舍

<a id="argument-19-failure-to-revision"></a>
### argument-19-failure-to-revision

**读者困难：**模型改进只写换了算法，读者不知道旧方案具体在哪里失效。

**写作动作：**保留一个足以击穿旧假设的具体反例，指出失败发生的对象、时刻或边界，再说明新约束补了哪一处缺口。复杂构型可用整体图定位、局部放大解释；若后续验证尚未完成，修订只能称待检验方案。

**适用条件：**已有真实失败记录或可核查反例，且能定位它违反的原假设。

**先有这些依据：**旧假设及对应失败记录；修订前后唯一变化或明确列出的变化；新方案覆盖旧反例和其他必要情形的验证。

**不要据此推出：**虚构试错历史；只画失败图却宣称新模型已经全面有效。

<a id="argument-20-fixed-policy-scenario-matrix"></a>
### argument-20-fixed-policy-scenario-matrix

**读者困难：**不同环境分别优化后得到很多收益，却没有说明真实部署前应该选择哪份方案。

**写作动作：**把候选方案和评价环境分成两个轴：固定每份可执行方案，再在同一组环境中计算结果。说明方案何时确定、信息何时可得，以及如何按已声明的风险或收益准则选择。

**适用条件：**方案在不确定环境实现前需作出，且候选可固定重评；允许适应性决策时明确其信息规则。

**先有这些依据：**固定候选及生成数据；共同评价环境与生成过程；选择准则和独立验证范围。

**不要据此推出：**把各环境事后最优收益的平均值当成单一部署方案收益；把候选集最优写成全域最优。

<a id="argument-31-domain-of-impossibility"></a>
### argument-31-domain-of-impossibility

**读者困难：**证明或搜索只覆盖固定边界条件，却把结论写成任何设计都无法改进。

**写作动作：**写清不变量或最优结论所属的可行域；放宽条件时明确哪一个自由度恢复，再讨论新空间中的候选。共享结论可以引用，但需重新检查它的适用条件。

**适用条件：**结论依赖固定端点、固定结构、固定信息或有限候选集。

**先有这些依据：**原可行域与证明范围；放宽的条件；新方案全程可行性或明确待检验状态。

**不要据此推出：**有限网格找不到改进就证明不可能；增加自由度后直接沿用旧最优性。

<a id="argument-32-bound-and-attaining-construction"></a>
### argument-32-bound-and-attaining-construction

**读者困难：**给出理论下界或一个可行方案后直接宣布最优，缺少连接两者的论证。

**写作动作：**分别承担界与可达性的责任：先由容量或守恒建立界，再展示满足全部限制的构造是否达到该界；若存在间隙，如实报告界、当前方案及差距，不改写为已经证明最优。

**适用条件：**离散配置或调度问题存在可解释的界，且构造能独立核查。

**先有这些依据：**界的成立条件；构造的逐项可行性；目标值与界的比较。

**不要据此推出：**只证明必要条件便当充分条件；给单一规模算例就宣称所有规模均达到界。

<a id="statistical-01"></a>
### statistical-01

**读者困难：**读者知道用了复杂模型，却不知道新增结构解决了哪一种数据困难。

**写作动作：**把模型选择写成逐项可检验的理由：先说明观测如何成组、响应范围和待解释形状，再将新增结构与对应诊断一一连接；报告不支持的项，让选择过程保留可被否定的分支。

**适用条件：**候选结构有明确的数据或任务动机，比较对象及检验前提可以说明。

**先有这些依据：**观测单位与独立样本数；候选结构的差异；适用的比较口径和拟合方式；与最终用途对应的验证结果。

**不要据此推出：**看到纵向数据便强制采用某种模型；把不显著说成无作用；仅据热力图排除简单基线；把模型拟合曲线当成独立验证。

<a id="statistical-03"></a>
### statistical-03

**读者困难：**读者无法判断清洗是在纠正错误，还是把模型最需面对的困难样本删掉。

**写作动作：**将异常发现、错误认定和决策排除分开写：给出异常规模与判据，说明哪个证据支持更正或删除，若只是低质量对象则保留其风险含义，并展示处理选择怎样改变后续评价。

**适用条件：**数据预处理会改变样本总体、候选集合或风险分布时。

**先有这些依据：**异常记录数量及占比；原始字段核查与错误证据；处理前后样本和结果比较；保留、降权或排除各自服务的目标。

**不要据此推出：**为了让评分或回归好看而删除表现差的对象；把商业低可靠性等同测量错误；用假设证明数据绝对无误。 把原表破折号或空字符串静默改为零，或擅自更改可疑数字字符串。

<a id="decision-01-threshold-and-priority-tradeoff"></a>
### 阈值与优先级的取舍

**读者困难：**阈值、权重或优先次序直接出现，读者不知道代价与来源。

**写作动作：**分别说明阈值偏小与偏大的损失、取值来自规范、数据、调试还是偏好。多目标问题解释先保什么、允许牺牲多少，以及次级目标还剩什么调整空间。

**适用条件：**现有任务确实包含门槛、权重、优先级或宽容度；没有依据的数值保留为待定。

**先有这些依据：**取值来源与数据范围；两侧损失或冲突目标；优先规则和容许变化。

**不要据此推出：**将某篇的7像素推广成常量；以矩阵一致性当公众偏好已被验证；以余量建议保证调度可行。

## 计算与执行

<a id="argument-21-action-and-post-state"></a>
### argument-21-action-and-post-state

**读者困难：**算法步骤列出了动作，却看不出下一步是否拥有所需资源或信息。

**写作动作：**在会改变后续可行性的关键动作后，给出更新后的状态。时间表可将动作、流入流出和后状态放在同一行；递推式则明确更新发生在本期起点还是终点。

**适用条件：**存在跨期资源、库存、信息或可达状态依赖；简单无状态过程无需额外状态表。

**先有这些依据：**初始状态；动作的前置条件；状态转移与守恒关系；终止条件。

**不要据此推出：**只增添Step编号；把本期尚未到达的资源供给本期动作。

<a id="argument-22-decode-decision"></a>
### argument-22-decode-decision

**读者困难：**结论只给策略编号、二进制串或最优变量值，执行者还要自行解码。

**写作动作：**保留变量顺序和候选比较供复核，再把选定方案翻译成对象明确的行动，并带上与比较表一致的效益口径。短策略可直接用一句话，不必再造一张表。

**适用条件：**模型输出对应离散行动或执行计划，编码映射已稳定。

**先有这些依据：**每一位或每个索引的语义；选定解及可行性；一致的规模、单位和指标。

**不要据此推出：**从编号猜动作；正文写检测、表里却是不检测；把批量收益写成单件收益。

<a id="argument-23-information-availability"></a>
### argument-23-information-availability

**读者困难：**算法用什么信息与研究者事后用什么指标评价混在一起，看起来可能偷看了未来或全局真值。

**写作动作：**分清观测量、估计量、目标值与仅供评估的真值。围绕一次实际决策说明当时可见的字段和历史范围，再单独说明离线评价为什么可以使用更完整的信息。

**适用条件：**在线、分布式、预测或缺测任务的信息权限会影响方案是否成立。

**先有这些依据：**决策时点的可用信息；估计与真值的来源；评价量未进入策略输入的执行证据。

**不要据此推出：**只声明没有泄漏却不检查输入；把事后全局误差用来驱动本应局部的决策。

<a id="argument-24-tolerance-not-digits"></a>
### argument-24-tolerance-not-digits

**读者困难：**计算报告很多小数和迭代轮数，却没有解释什么时候已经足够回答实际问题。

**写作动作：**先说明应用允许的误差及量纲，再将误差随成本或轮次的变化连接到停止选择。区分数值残差、对象误差和决策容差；只能在已建立的转换关系下互相推断。

**适用条件：**存在真实容差或可解释的收益—代价准则，且停止后仍满足约束。

**先有这些依据：**容差来源；误差指标与实际目标关系；误差/成本轨迹和停止后的可行性。

**不要据此推出：**把机器精度当工程必要精度；看到曲线平台就自行发明足够准确的门槛。

<a id="argument-27-data-explains-index-axes"></a>
### argument-27-data-explains-index-axes

**读者困难：**参数突然带上多个下标，读者不知道哪些维度真正改变它。

**写作动作：**用同对象跨条件的可比记录说明参数随哪些轴变化，再定义恰好需要的索引。矩阵的行和列若对应不同管理对象，分别解释两个方向求和的业务含义。

**适用条件：**有多维记录或明确的结构假设支持参数的依赖范围。

**先有这些依据：**维度与实体映射；跨条件可比记录或约束依据；例外与缺测范围。

**不要据此推出：**从两行样例推断所有对象都不受某因素影响；给所有参数机械添加全部下标。

<a id="argument-30-task-specific-missingness"></a>
### argument-30-task-specific-missingness

**读者困难：**预处理一概删除缺失记录，没有解释这会改变哪些研究对象。

**写作动作：**先区分每项分析需要哪些字段，再解释同一条不完整记录为什么可用于一种统计、不能用于另一种匹配。把缺测、无事件与数值零分别编码，并保留对应样本范围。

**适用条件：**共享数据服务不同任务，字段缺失不意味着记录的所有信息均无效。

**先有这些依据：**字段需求与缺失分布；分别保留/剔除的数量及总体；去重、漏检和零值定义。

**不要据此推出：**自动宣称保留异常提高鲁棒性；识别字段缺失后仍将重复记录当独立对象计数。

<a id="argument-34-theory-to-executed-computation"></a>
### 理论与实际计算的衔接

**读者困难：**精细理论公式与最终程序结果之间，只剩一句“编程求解”。

**写作动作：**在衔接处交代实际实现保留了什么、离散或替换了什么、为什么以及可能改变哪些输出。比较两次计算时并列真实变化；不能仅因参数表相似就宣称只改变网格或精度。

**适用条件：**已有实现说明或运行记录；仅有理论时不能补写实际执行细节。

**先有这些依据：**理论表达和实际计算规则；采样、停止与边界设置；被比较运行的真实差异。

**不要据此推出：**让精细理论替简化计数保证准确；把同时改变分摊规则的结果仅归因于网格加密。

<a id="interface-01-artifacts-and-human-steps"></a>
### 附件及人工步骤的接口

**读者困难：**裸矩阵、图像附件或代码存在，却不说明它们怎样进入结果。

**写作动作：**交代文件与变量、行列、单位及步骤的对应；图像附件与解释它的正文一并阅读。人工选择、标注或识别在实际参与处明确说明，输出属于候选、人工确认还是最终结果要一致。

**适用条件：**正文依赖附件、脚本输出或交互步骤；已有接口和实际流程可查。

**先有这些依据：**附件实际内容与正文引用；输入输出的维度和编码；人工步骤及其触发条件。

**不要据此推出：**把文件存在当复现；从一个条件分支推断其余全部自动；把模型交互输出称为独立真值。

<a id="writing-unified-03"></a>
### 初试与未决缺口

**读者困难：**试探、失败和未完成步骤常被收束为成功叙事，缺少停止点、已知结果和可验证后续。

**写作动作：**分别写已做的初试及其结果、在哪个问题停止、尚未尝试的步骤和可验证后续；定性结果保持定性。

**适用条件：**报告包含试探、失败或未完成的过程。

**先有这些依据：**运行/检查记录、停止点、未解问题。

**不要据此推出：**不能补造准确率、优越性或完成状态。

<a id="writing-unified-06"></a>
### 多阶段流程与输出角色

**读者困难：**同一中间结果在探索、筛选、估计、验证和建议阶段承担不同责任，单列步骤会掩盖这种证据角色变化。

**写作动作：**按实际依赖说明阶段输入、输出和下一步用途，区分探索、筛选、估计、验证和行动建议；同名算法在不同阶段按对象和输出重新标注。

**适用条件：**步骤或模型确实跨阶段传递信息、状态或证据。

**先有这些依据：**每阶段输入输出、状态更新、实际完成和未完成项。

**不要据此推出：**不能因为步骤排列整齐就宣称已完成验证、全自动或最优；未执行阶段保持建议。

<a id="writing-unified-08"></a>
### 搜索覆盖与停止理由

**读者困难：**有限搜索的停止点和覆盖域常被省略，稳定的局部结果因而看似全域结论。

**写作动作：**报告搜索、枚举或迭代实际覆盖的区域、已有界/可行性证据和停止点，并限定这些证据支持的结论强度。

**适用条件：**答案由有限搜索或迭代得到且覆盖和停止可记录。

**先有这些依据：**搜索域、停止记录、界/构造与结论层级。

**不要据此推出：**不能把一次稳定或局部搜索写成全域最优。

## 图表与叙述

<a id="argument-28-complementary-views"></a>
### argument-28-complementary-views

**读者困难：**一个三维对象的轴、截面和离散索引挤在透视图里，公式仍无法对应。

**写作动作：**让互补视图各解释一种必要关系，例如侧视定义轴向角、截面定义径向和周向索引；用一致符号明确它们是同一对象，再回到离散式。能用一幅二维图解释时不强行增加视图。

**适用条件：**单一投影确实隐藏影响公式理解的自由度，第二视图提供新信息而非装饰。

**先有这些依据：**实体与投影关系；轴和索引的定义；采样权重及测度。

**不要据此推出：**把视觉上均匀划分当成等面积或等能量采样；增加漂亮三维图但不标公式对象。

<a id="writing-unified-05"></a>
### 多案例组织与互补视角

**读者困难：**多个案例或视角被排版结构混成同一证据。

**写作动作：**说明共享对象、互补证据和不可合并差异；不把多案例组织等同于多维图表。

**适用条件：**确有多个案例、视角或表示。

**先有这些依据：**案例对象、共享关系和互补证据。

**不要据此推出：**不能以统一排版掩盖对象差异。

<a id="writing-unified-07"></a>
### 局部误差定位

**读者困难：**全局误差掩盖关键区域。

**写作动作：**呈现局部误差变化及其决策意义。

**适用条件：**局部区域决定结论。

**先有这些依据：**局部误差记录。

**不要据此推出：**不要求新增实验。

## 结果与边界

<a id="statistical-09-evaluation-question-resolution"></a>
### statistical-09-evaluation-question-resolution

**读者困难：**一组很高的总体指标似乎回答了一切，却没有区分发现问题与辨明具体问题这两个不同用途。

**写作动作：**在给指标前先说明评价究竟要回答哪个问题；任务确有粗细两层时，分别解释发现目标与辨别类型的证据。把细分样本数、失败类型和指标接回相应问题，不让总体成功替代困难子类的表现。

**适用条件：**同一任务确实含有不同分辨层次或使用目的，且已有相应标签与评价结果；单一目标或没有细类标签时，不制造第二层评价。

**先有这些依据：**各评价问题及其标签、分母、样本来源；相应层次的结果与细类样本数；汇总指标与细分类指标是否同一划分、是否能相互核对。

**不要据此推出：**强制每个分类任务都做两层模型；从两个罕见样本全对推出普遍保证；把逻辑规则的设计目标当成已测召回率；替来源填补矛盾指标。

<a id="argument-25-rigid-total-flexible-composition"></a>
### argument-25-rigid-total-flexible-composition

**读者困难：**敏感性结果只写影响较小，掩盖了总量不变但内部组成发生调整。

**写作动作：**先分开总量与组成的响应，再检查硬约束是否固定了总量、内部自由度是否允许替换。用实际方案变化支持解释；若只有约束逻辑而没有输出对照，就将其作为待验证的解释。

**适用条件：**汇总指标可能抵消个体变化，或硬约束限制总量而不限制内部配置。

**先有这些依据：**同条件的扰动前后方案；约束及其是否活跃；总量与组成指标的定义。

**不要据此推出：**用平均不变证明所有对象稳健；未经检查就把平台归因于某条约束。

<a id="argument-26-predicted-perturbation"></a>
### argument-26-predicted-perturbation

**读者困难：**检验只说曲线合理，没有说明如果机制成立，改变条件应看到什么。

**写作动作：**从已陈述机制推导一个可辨认的方向、对称性或边界变化，再用真实对照检查该预期。解释一致性支持了哪一层，不把定性方向正确升级为所有参数和实现均正确。

**适用条件：**机制给出可被反驳的预期，并已有或获授权获取相应对照证据。

**先有这些依据：**变化前明确的机制预期；控制条件；实际响应与不符合预期的部分。

**不要据此推出：**看完图再编造事先预期；写作任务中偷偷增做实验或编写验证结果。

<a id="argument-29-terminal-value-versus-process"></a>
### argument-29-terminal-value-versus-process

**读者困难：**方案仅按最终收益排序，读者看不到达到收益所需的处理轮次和资源占用。

**写作动作：**在同一实际过程尺度上比较收益轨迹与终值，指出领先关系何时改变，再判断时间或周转成本是否会改变选择。把经营轮次、真实时间和优化器迭代分别命名。

**适用条件：**过程长度本身影响决策且已有轨迹；若只知道优化器迭代次数，不解释成经营耗时。

**先有这些依据：**同口径轨迹与终值；轮次对应的真实代价；选择准则。

**不要据此推出：**把终值低和终值高的方案同时称为同一目标下全局最优；用轮数替代未经测量的工时。

<a id="statistical-02"></a>
### statistical-02

**读者困难：**读者看见曲线，却分不清条件变化、模型不确定性和实际决策门槛。

**写作动作：**图前说清固定哪些条件、改变哪个变量以及阴影和参考线的含义；图后只指出与问题有关的方向、阈值交会和不确定区域，再解释它们如何影响决策。

**适用条件：**图中对象、条件和参考线与模型及题目一致；图能够承载具体判断。

**先有这些依据：**绘图数据与生成口径；置信带或预测带的计算定义；参考阈值来源；边缘区间样本支持度。

**不要据此推出：**把均值置信带解释为个体达标概率；用预测曲线的形状再次证明模型正确；不交代条件就宣称普遍规律。

<a id="statistical-04"></a>
### statistical-04

**读者困难：**总成本或总误差变化可能只是业务规模变化，读者无法判断方案效率是否改善。

**写作动作：**在同一比较表保留总量、服务产出和单位产出指标；先解释分母为什么是任务关心的效用，再在相同约束和信息条件下比较。若参照用了事后信息，明确其只作理想参照。 同时注明基线是观测、历史估计还是事后理想参照；人次、人数、单次、人天的分母不能互换。比例超过100%未必错误，应回到定义。

**适用条件：**被比较方案服务规模不同，或者评价基准的信息权限不同。

**先有这些依据：**总量与分母的单位和时间窗；相同任务约束下可行性；在线方案与事后参照的信息范围；相同数据上的可执行基线及误差范围。

**不要据此推出：**比历史均值低即宣称全局最经济；比较不同规模时只挑有利指标；允许在线方案使用未来真实损耗。 将出游人次数/人口数当作去重人数占比；将模型收益减历史估计写成实测增益。

<a id="statistical-05"></a>
### statistical-05

**读者困难：**读者看见平均改善，却不知道改善集中在哪里、是否足以改变决策，以及为何提升有限。

**写作动作：**将决策变量的实际调整与逐期绩效变化连接起来，同时给平均与局部幅度；提升有限时提出可检查的约束解释，并说明放松哪项条件才可能获得额外收益。

**适用条件：**改进方案可与原方案逐对象或逐时期配对，且收益可能受约束限制。

**先有这些依据：**同口径基线；逐期或分组改变量；平均改善的加权方式；候选瓶颈的松弛试验或约束余量。

**不要据此推出：**将局部最大值当典型收益；由调整量大推断结构全局最优；把可行域受限的推测写成已证实原因。

<a id="statistical-07"></a>
### statistical-07

**读者困难：**成功率或平均误差很漂亮，读者却不知道成功如何定义、对哪些案例有效、是否能推广。

**写作动作：**先交代试验生成机制、覆盖范围、成功判据和误差单位，再呈现汇总指标及代表实例；将仿真内成功、实测可用和一般性保证分开命名。 参数相对基准模型的变化属于敏感性；相对独立观测的差才是相应观测误差。先说参照，再命名检验。

**适用条件：**使用抽样仿真、分类成功率、定位误差或可行解比例支持决策时。

**先有这些依据：**随机分布、范围和种子；样本计数与覆盖情形；成功阈值及单位；失败或最差案例；独立实测或外推试验，如有。

**不要据此推出：**有限样本全部成功即宣称所有情形保证；混淆识别成功与坐标无误差；以平均值掩盖退化几何或极端案例。

<a id="statistical-08"></a>
### statistical-08

**读者困难：**限制段只说条件严格、数据不足，读者不知道自己的实例还能否采用方案。

**写作动作：**把限制落到可判定的输入条件，说明它在哪一步被使用、失效会阻断哪个输出，以及应改用何种补充观测或重新验证；把尚未验证的推广留在条件句里。

**适用条件：**方法依赖某种初始构形、数据支持范围、供给规则或测量可用性时。

**先有这些依据：**关键前提与使用它的推导步骤；可检测的适用性条件；条件失效的例子或分析；替代措施及重新验证所需证据。

**不要据此推出：**限制段只列未考虑因素；正文无条件推荐，结尾再补一句泛化待验证；认为曾在一种规模成功就能任意扩容。

<a id="writing-unified-02"></a>
### 分组结构与解释范围

**读者困难：**总体平均或单一关系掩盖了不同组的对象与机制差异。

**写作动作：**解释已采用的分组依据、各组口径和关系差异，并限定可比较和可推广的范围。

**适用条件：**已有分析区分组别、阶段或区间，且差异会影响结果解释。

**先有这些依据：**分组定义及样本范围；实际分组结果和解释依据。

**不要据此推出：**不凭分组表现臆造机制，也不将组内关系直接推广到总体。

<a id="writing-unified-04"></a>
### 图表结果解释

**读者困难：**图表的视觉趋势并不会自动说明指标、机制或安全意义，需要把编码、范围、例外与实际结论逐一接上。

**写作动作：**图前说明对象、固定条件、编码和范围；图后只提取与问题有关的趋势、例外和不确定区域，并把视觉结果连接到实际指标而不越过检验层。

**适用条件：**图表承载了模型判断或结果比较。

**先有这些依据：**图表编码、数据范围、对照口径和实际支持层级。

**不要据此推出：**不能用图形外观证明照度、安全、收敛或一般性；也不能以制作流程替代解释。

<a id="writing-unified-12"></a>
### 条件对齐冲突

**读者困难：**表格、正文和不同子问的表面冲突可能来自对象、窗口、分母或计算层不同，需先对齐再裁决。

**写作动作：**遇到结果不一致时先对齐对象、时间/场景、约束、分母和计算层；条件不同则分别陈述，真正同口径冲突才降低结论强度。

**适用条件：**正文、图表或跨问结果表面冲突。

**先有这些依据：**冲突两侧定位、比较条件和裁决记录。

**不要据此推出：**不能按日期、数量或流畅程度选最漂亮的结论。

<a id="writing-unified-16"></a>
### 目标与决策变量依赖

**读者困难：**目标式中出现变量不代表该变量真正改变目标，需防止形式相关被写成优化效果。

**写作动作：**在声称优化某目标前，用定义代回或最小变动对照说明决策变量实际改变的项；目标退化时改写为约束或次级目标的作用。

**适用条件：**目标函数可能与决策变量脱钩或仅间接相关。

**先有这些依据：**目标定义、代回/对照、约束和支持范围。

**不要据此推出：**不能把形式上出现的变量写成已改善目标。

<a id="writing-unified-17"></a>
### 简化近似与可达性

**读者困难：**理想界、近似构造和实际可达方案常被合并成“最优”，读者看不到差距及近似阻断的更强主张。

**写作动作：**使用简化模型、边界、分解或启发式结果时，分别报告其理论界/参考、实际构造和差距，并说明近似何时阻断更强结论。

**适用条件：**复杂问题采用了近似、分解、局部搜索或边界比较。

**先有这些依据：**可行域、界、构造、差距及实际验证。

**不要据此推出：**不能命令读者采用某一算法、把局部最优写成全局最优或把理想下限写成实测结果。

<a id="writing-unified-20"></a>
### 结果证据强度与措辞

**读者困难：**数值观察、模型内一致性、外部对照和机制解释常被压成同一个“证明”措辞，导致结论越过证据。

**写作动作：**把观察到的数值、模型内一致性、外部对照和机制解释分层命名；证据不足时降低措辞强度，并写出尚未支持的结论。

**适用条件：**结果主张跨越描述、预测、因果或保证层级时。

**先有这些依据：**观测对象、比较对象、检验范围、主张层级。

**不要据此推出：**拟合、回代、一次仿真或方向一致不能被写成外部验证、因果机制或普遍保证。

<a id="writing-unified-21"></a>
### 范围口径与状态分层

**读者困难：**输入、重建、展示、检验和不同时间窗常共用一个总量名称，读者无法知道结果实际覆盖谁。

**写作动作：**在结果、图表或摘要旁标明输入、处理/重建、展示、实际检验及时间窗口的范围；将缺失、等待、服务后状态和版本变更分别命名。

**适用条件：**同一资料服务多个阶段、子集、时间窗或状态，范围差异会改变解释。

**先有这些依据：**各范围的对象清单、时间起止、分母/状态字段及复用条件。

**不要据此推出：**不能用“处理过”“可生成”或一个总量掩盖实际未检验的对象，也不能把不同时间窗直接比较。

<a id="writing-unified-22"></a>
### 证据链与独立核验

**读者困难：**多次同源计算或回代容易被称为“互证”，需要指明独立路径、比较对象和实际核验范围。

**写作动作：**关键结果需要复核时，说明采用的独立路径或原方程检查、比较对象和核验范围；简单计数无需堆叠检查，未做的核验保持为计划。

**适用条件：**结果对求解器、近似、转换或复杂数据链条敏感。

**先有这些依据：**原始输入、独立路径、差异阈值和实际完成状态。

**不要据此推出：**不能把多种同源计算、重新表述或一次回代当作独立外部证据。

## 归属与修订

<a id="source-01-attribution-and-version"></a>
### 来源、版本与事实归属

**读者困难：**混排段落、评述或异版OCR被当作同一作者的独立证据。

**写作动作：**先确认段落属于作者、评注、题面还是附件，再在实际使用处保留归属。遇到摘要错配、转页接续或后续纠正，采用已回查的具体解释，并让被替代判断退出当前写作；同作品异版只补缺不加票。

**适用条件：**借用文献、历史范文或多版本资料进行表述与经验归纳时。

**先有这些依据：**版本与段落边界；原件或有定位的纠正记录；具体主张的归属。

**不要据此推出：**以目录获奖标签认证结论；把编者批评写成作者自证；把新版日期当作无条件真理；用一篇文章的摘要填另一篇。

<a id="revision-01-respond-to-substantive-feedback"></a>
### 回应实质反馈

**读者困难：**修订说明宣称新颖或已改，却没有回答原问题。

**写作动作：**对实际收到的意见说明问题、对应修改及仍未解决之处。质疑涉及对象、论证或证据时回应同一层；文字改好并不解决缺失的模型验证。

**适用条件：**确实有反馈或修订要求；普通初稿不虚构审稿过程。

**先有这些依据：**反馈原文；被改段落及版本；仍需分析的问题。

**不要据此推出：**以“无类似报道”回答方法或代码相似质疑；把建议检查说成已经检查；对所有初稿强制写回复信。
